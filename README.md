## Networks by Region
  
### Latin America
- [Altermundi](https://altermundi.net/) - Community network project in Quintana, Argentina, focused on connecting rural areas through mesh technology and local governance.
- [CARC](https://carc.libre.org.ar/) - Community network cooperative in Argentina promoting free telecommunications and digital rights.
- [Coolab](https://coolab.org/) - Brazilian cooperative laboratory for community networks and digital culture.
- [ElValleReinicia](https://radioslibres.net/conoce-a-la-red-comunitaria-el-valle-reinicia/) - Community network initiative in Las Calles, Córdoba, Argentina.
- [MonteNet](https://montelibre.net/) - Community-owned network serving Molinari, Argentina.
- [NonoLibre](https://programafrida.net/archivos/project/red-traslasierra) - Community mesh network in Nono, Traslasierra Valley, Argentina.
- [Rede Mocambos](https://mocambos.net/) - Network of quilombola communities in Brazil using technology for cultural preservation and communication.
- [TIC A.C.](https://ticac.org/) - Indigenous community-owned cellular and mesh network in Mexico.

### Europe
- [Antennine](https://antennine.org/) - Community wireless network in Palermo, Sicily.
- [AWMN](https://www.awmn.net/) - Athens Wireless Metropolitan Network in Greece.
- [Freifunk](https://freifunk.net/) - Decentralized community mesh network initiative across Germany with hundreds of local groups.
- [FunkFeuer](https://funkfeuer.at/) - Free experimental community network with nodes across Austria.
- [Guifi.net](https://fundacio.guifi.net/) - One of the world's largest community networks, based in Catalonia, Spain, with thousands of active nodes.
- [Ninux](http://wiki.ninux.org/) - Wireless community network spanning multiple cities across Italy.
- [Sarantaporo.gr](https://sarantaporo.gr/) - Community wireless network connecting mountain villages in Thessaly, Greece.

### Africa
- [TunapandaNET](https://www.apc.org/en/users/tunapanda-institute) - Community network and learning platform in Kenya providing connectivity and digital skills training.
- [Zenzeleni](https://zenzeleni.net/) - Community-owned telecommunications cooperative in rural South Africa.

### Asia
- [Common Room Networks Foundation](https://commonroom.info/) - Community networks empowering indigenous and rural villages in West Java, Indonesia.
- [Digital Empowerment Foundation](https://defindia.org/) - Digital literacy and community networks across rural India.
- [Rhizomatica](https://rhizomatica.org/) - Community cellular network initiative in the Philippines enabling communities to build their own telecommunications infrastructure.

### North America
- [NYC Mesh](https://nycmesh.net/) - Community-owned mesh network ending the digital divide in New York City.
- [People's Open Network](https://github.com/sudomesh) - Community wireless mesh network in the Bay Area, Oakland, USA.
- [Seattle Community Network](https://seattlecommunitynetwork.org/) - Community-run 4G LTE network for fair internet access in Seattle, USA.
- [Seattle Community Network (SCN)](https://www.scn.org/) - Free public-access network since 1994 in Seattle, USA.
- [Vancouver Community Network](https://www2.vcn.bc.ca/) - Free community network providing internet access and digital equity in Canada.

## Tools & Software

- [batman-adv](https://www.open-mesh.org/) - Layer-2 mesh routing protocol used by Freifunk, LibreMesh, gluon.
- [BMX7](https://github.com/bmx-routing/bmx7) - Securely Entrusted Mesh Routing Protocol for Linux.
- [CJDNS](https://github.com/cjdelisle/cjdns) - Encrypted IPv6 mesh network using public-key cryptography.
- [FIPS](https://github.com/jmcorgan/fips) - Self-organizing encrypted mesh network built on Nostr identities.
- [gluon](https://gluon.readthedocs.io/en/latest/) - Framework for building custom OpenWrt-based firmware for mesh networks, used by Freifunk communities.
- [LibreMesh](https://libremesh.org/) - Open-source firmware solution for creating and managing wireless mesh networks with minimal configuration.
- [Meshenger](https://github.com/dakhnod/Meshenger) - Android messaging app that works over local WiFi mesh networks without internet connectivity.
- [Meshtastic](https://meshtastic.org/) - Open-source LoRa-based mesh communication platform for off-grid messaging and GPS tracking.
- [nostr-vpn](https://github.com/mmalmi/nostr-vpn) - Tailscale-style private mesh VPN using FIPS data plane.
- [OLSRd](https://www.olsr.org/) - Optimized Link State Routing protocol for mesh networks.
- [OpenWRT](https://openwrt.org/) - Linux-based open-source firmware for embedded devices, widely used as the foundation for mesh network routers.
- [Qaul](https://github.com/qaul/qaul.net) - Decentralized communication application for mesh networks enabling file sharing and messaging.
- [Reticulum](https://reticulum.network/) - Cryptography-based networking stack for building resilient mesh networks over diverse physical mediums.
- [Retroshare](https://retroshare.cc/) - Decentralized communication platform supporting encrypted chat, forums, and file sharing over mesh networks.
- [TollGate](https://github.com/OpenTollGate/tollgate-module-basic-go) - Bearer instruments for transport on OpenWRT.
- [wifistr](https://github.com/hzrd149/wifistr) - Open WiFi map powered by Nostr.
- [Yggdrasil](https://yggdrasil-network.github.io/) - Experimental end-to-end encrypted IPv6 overlay network with automatic routing.

## Hardware Projects

- [LibreRouter](https://github.com/librerouter) - Open-hardware router designed specifically for community networks.
- [Mesh Potato](https://www.villagetelco.org/) - Low-cost mesh telephony device combining WiFi mesh networking with VoIP capabilities for rural areas.
- [Meshbox](https://github.com/libremesh/lime-packages) - Plug-and-play mesh network router hardware running LibreMesh firmware.
- [OpenWrt-One](https://openwrt.org/toh/openwrt/one) - Reference hardware platform designed specifically for OpenWrt development and deployment.
